# Super Admin Authentication

---

## 1. Module Overview

- **Module Name:** Super Admin Authentication
- **Platform:** Admin Web / Backoffice
- **Layout Type:** Desktop
- **Primary Role(s):** Super Admin
- **Goal:**  
  Enable secure Super Admin access to the Admin Web / Backoffice using email-password login, OTP verification, password reset via OTP, and logout.

---

## 2. Navigation & Entry Points

### 2.1 Left Navigation / Global Entry
- **Menu Label:** Not applicable; authentication entry screens are accessed before the authenticated Admin Web navigation is available.
- **Menu Icon (suggested):** Not applicable
- **Menu Level:** Not applicable
- **Default Landing Screen ID:** SA-AUTH-LOGIN-01

### 2.2 Visibility Rules
- Visible to:
  - ✅ Super Admin
  - ❌ Any non-Super Admin role

## 4. Screens & Interaction Specs

### 4.1 Login Screen

- **Screen ID:** SA-AUTH-LOGIN-01
- **Screen Type:** Form
- **Primary Action:** Login
- **Secondary Actions:** Forgot Password

#### Entry Points
- Admin Web / Backoffice URL opened by unauthenticated user
- Redirect after logout
- Redirect after expired or invalid session
- Redirect after successful password reset

#### UI Layout
- Centered authentication card
- Page title: Login
- Short helper text: Enter your Super Admin credentials to continue.
- Email field
- Password field
- Primary Login button
- Forgot Password link below password field
- Form-level message area above actions

#### Components
- Email input
- Password input
- Login button
- Forgot Password text link
- Loading spinner within Login button
- Form-level alert message

#### Form Fields
| Field | Type | Required | Default |
|------|-----|----------|--------|
| Email | Text | ✅ | — |
| Password | Password | ✅ | — |

#### Field Validation
| Field | Validation Rule | Validation Message |
|------|-----------------|-------------------|
| Email | Must be valid email format | Enter a valid email address. |
| Password | Must not be empty | Password is required. |

#### Navigation Rules
- Login with valid required fields → SA-AUTH-OTP-01
- Forgot Password → SA-AUTH-FORGOT-01
- Login failure → Remain on SA-AUTH-LOGIN-01
- Account inactive → Remain on SA-AUTH-LOGIN-01
- Lockout triggered → Remain on SA-AUTH-LOGIN-01

#### States
- **Loading:** Disable Email, Password, Login button, and Forgot Password link; show spinner in Login button.
- **Empty:** Not applicable for this form screen.
- **Error:** Show field-level and form-level messages based on validation result.
- **No-permission:** Show Access denied. if a non-Super Admin attempts to use the screen.

#### UX Copy
- Button: Login
- Link: Forgot Password?
- Invalid credentials message: Invalid credentials.
- Account inactive message: Account is not active.
- Lockout message: Too many attempts. Try again later.
- OTP provider failure message: Unable to send OTP right now. Please try again later.

---

### 4.2 OTP Verification Screen

- **Screen ID:** SA-AUTH-OTP-01
- **Screen Type:** Form
- **Primary Action:** Verify OTP
- **Secondary Actions:** Resend OTP

#### Entry Points
- Successful credential validation from SA-AUTH-LOGIN-01
- OTP resend action from the same screen

#### UI Layout
- Centered authentication card
- Page title: OTP Verification
- Helper text: Enter the 6-digit OTP sent to your registered channel.
- OTP input field
- Verify OTP button
- Resend OTP button or link
- Cooldown helper text below Resend OTP
- Form-level message area above actions

#### Components
- 6-digit OTP input
- Verify OTP button
- Resend OTP button/link
- Cooldown timer text
- Loading spinner within active action button
- Field-level validation message
- Form-level alert message

#### Form Fields
| Field | Type | Required | Default |
|------|-----|----------|--------|
| OTP | Text | ✅ | — |

#### Field Validation
| Field | Validation Rule | Validation Message |
|------|-----------------|-------------------|
| OTP | Exactly 6 numeric digits | Enter the 6-digit OTP. |

#### Navigation Rules
- Verify OTP success → Dashboard
- Invalid OTP → Remain on SA-AUTH-OTP-01
- Expired OTP → Remain on SA-AUTH-OTP-01
- Resend OTP success → Remain on SA-AUTH-OTP-01 and reset cooldown display
- Resend OTP within cooldown → Remain on SA-AUTH-OTP-01
- Resend OTP limit reached → Remain on SA-AUTH-OTP-01
- OTP verification lockout → Remain on SA-AUTH-OTP-01

#### States
- **Loading:** Disable OTP input, Verify OTP button, and Resend OTP action; show spinner for the active action.
- **Empty:** Not applicable for this form screen.
- **Error:** Show OTP validation, invalid OTP, expired OTP, cooldown, resend limit, lockout, or provider failure messages.
- **No-permission:** Show Access denied. if accessed by a non-Super Admin or without a valid pending OTP state.

#### UX Copy
- Button: Verify OTP
- Link/Button: Resend OTP
- Helper text: Enter the 6-digit OTP sent to your registered channel.
- Invalid OTP message: Invalid OTP.
- Expired OTP message: OTP expired. Please resend OTP.
- Cooldown message: Please wait 60 seconds before requesting a new OTP.
- Resend limit message: OTP resend limit reached. Try again later.
- Lockout message: Too many attempts. Try again later.
- OTP provider failure message: Unable to send OTP right now. Please try again later.

- Email input field
- Send OTP button
- Back to Login link

#### Components

- Send OTP button
- Back to Login text link
- Loading spinner within Send OTP button

- Form-level alert message

| Field | Type | Required | Default |
|------|-----|----------|--------|
| Email | Text | ✅ | — |

#### Field Validation
| Field | Validation Rule | Validation Message |
|------|-----------------|-------------------|

#### Navigation Rules

### 4.4 Reset Password Screen

- **Screen ID:** SA-AUTH-RESET-01
- **Screen Type:** Form
- **Primary Action:** Reset Password
- **Secondary Actions:** Back to Login

#### Entry Points
- Successful password reset OTP request from SA-AUTH-FORGOT-01

#### UI Layout
- Centered authentication card
- Page title: Reset Password
- Helper text: Enter the OTP and create a new password.
- OTP input field
- New Password field
- Confirm Password field
- Password policy helper text
- Reset Password button
- Back to Login link
- Form-level message area above actions

#### Components
- 6-digit OTP input
- New Password input
- Confirm Password input
- Password policy helper text
- Reset Password button
- Back to Login text link
- Loading spinner within Reset Password button
- Field-level validation messages
- Form-level alert message

#### Form Fields
| Field | Type | Required | Default |
|------|-----|----------|--------|
| OTP | Text | ✅ | — |
| New Password | Password | ✅ | — |
| Confirm Password | Password | ✅ | — |

#### Field Validation
| Field | Validation Rule | Validation Message |
|------|-----------------|-------------------|
| OTP | Exactly 6 numeric digits | Enter the 6-digit OTP. |
| New Password | Minimum 12 characters and must include uppercase, lowercase, number, and special character | Password does not meet policy. |
| Confirm Password | Must match New Password | Passwords do not match. |

#### Navigation Rules
- Reset Password success → SA-AUTH-LOGIN-01
- Invalid OTP → Remain on SA-AUTH-RESET-01
- Expired OTP → Remain on SA-AUTH-RESET-01
- Password policy fail → Remain on SA-AUTH-RESET-01
- Confirm password mismatch → Remain on SA-AUTH-RESET-01
- Rate or attempt limit hit → Remain on SA-AUTH-RESET-01
- Back to Login → SA-AUTH-LOGIN-01

#### States
- **Loading:** Disable all fields, Reset Password button, and Back to Login link; show spinner in Reset Password button.
- **Empty:** Not applicable for this form screen.
- **Error:** Show OTP, password policy, confirm mismatch, expired OTP, invalid OTP, lockout, or rate-limit messages.
- **No-permission:** Show Access denied. if a non-Super Admin attempts to use the screen.

#### UX Copy
- Button: Reset Password
- Link: Back to Login
- Password policy helper: Use at least 12 characters with uppercase, lowercase, number, and special character.
- Invalid OTP message: Invalid OTP.
- Expired OTP message: OTP expired. Please resend OTP.
- Password policy message: Password does not meet policy.
- Confirm mismatch message: Passwords do not match.
- Rate or attempt limit message: Too many attempts. Try again later.
- Success message on Login screen: Password reset successful. Please log in.

---

### 4.5 Logout Screen

- **Screen ID:** SA-AUTH-LOGOUT-01
- **Screen Type:** Action / Redirect
- **Primary Action:** Logout
- **Secondary Actions:** None

#### Entry Points
- Logout action from authenticated Admin Web session

#### UI Layout
- Transitional logout state
- Optional centered loading card
- Message: Signing you out...
- No form inputs

#### Components
- Loading spinner
- Redirect message

#### Navigation Rules
- Logout success → SA-AUTH-LOGIN-01
- Logout failure → SA-AUTH-LOGIN-01 with generic safe message

#### States
- **Loading:** Show spinner and Signing you out... message.
- **Empty:** Not applicable.
- **Error:** Redirect to SA-AUTH-LOGIN-01 and show safe generic message if needed.
- **No-permission:** Not applicable for authenticated logout action. If accessed without an authenticated session, redirect to SA-AUTH-LOGIN-01.

#### UX Copy
- Loading message: Signing you out...
- Redirect message: You have been logged out.
