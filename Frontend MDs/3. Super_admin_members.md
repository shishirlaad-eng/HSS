# Members Management

---

## 1. Module Overview

- **Module Name:** Members Management
- **Platform:** Admin Web
- **Layout Type:** Desktop
- **Primary Role(s):** Super Admin
- **Goal:**  
  Enable Super Admins to manage system-wide member records across all Masters scopes, including listing, search, filters, member details, create/edit actions, lifecycle governance, CSV export, and CSV bulk upload while preserving safeguarding, audit, and dependency rules.

---

## 2. Navigation & Entry Points

### 2.1 Left Navigation / Global Entry
- **Menu Label:** Members
- **Menu Icon (suggested):** users
- **Menu Level:** Primary

## 4. Screens & Interaction Specs

### 4.1 Members Listing Screen

- **Screen ID:** MEM-LIST-01
- **Screen Type:** Listing
- **Primary Action:** Add Member
- **Secondary Actions:** View, Edit, Deactivate, Reactivate, Delete, Export CSV, Bulk Upload, Retry

#### Entry Points
- Click Members from Admin Web left navigation.
- Redirect after create, update, deactivate, reactivate, delete, export, or bulk upload action.
- Back action from Member Details.

#### UI Layout
- Page Header: "Members"
- Helper Text: "Manage member records across all Masters scopes."
- Advanced Filter Bar
- Primary CTA: Add Member
- Secondary CTAs: Bulk Upload, Export CSV
- Data Table
- Pagination
- Toast notification region

#### Components
- Search input for Name, Email, Phone, or Member ID
- Country/Org dropdown filter
- Region dropdown filter, cascaded by Country/Org
- Town dropdown filter, cascaded by Region
- Activity Centre dropdown filter, cascaded by Town
- Member Type dropdown filter: Adult, Teen, Child
- Status dropdown filter: Pending Parental Consent, Pending Approval, Active, Rejected
- DBS Status dropdown filter: Pending, Completed
- First Aid Status dropdown filter: Pending, Completed
- Add Member button
- Bulk Upload button
- Export CSV button
- Members data table
- Row action buttons: View, Edit, Deactivate/Reactivate, Delete
- Pagination controls
- Retry button for load failures

#### Data Table
| Column | Type | Click Behavior | Notes |
|------|-----|----------------|------|
| Member ID | Text | Click -> MEM-DETAIL-01 | Primary identifier |
| Member Name | Text | Click -> MEM-DETAIL-01 | Show member display name |
| Member Type | Badge | None | Adult / Teen / Child |
| Masters Scope | Text | None | Country/Org, Region, Town, Activity Centre |
| Status | Badge | None | Pending Parental Consent / Pending Approval / Active / Rejected |
| DBS Status | Badge | None | Pending / Completed |
| First Aid Status | Badge | None | Pending / Completed |
| Contact | Masked Text | None | Minimize PII in listing view |
| Actions | Buttons | View / Edit / Deactivate-Reactivate / Delete | Destructive actions require confirmation |

#### Navigation Rules
- Members menu -> MEM-LIST-01
- Member ID click -> MEM-DETAIL-01
- View -> MEM-DETAIL-01
- Add Member -> MEM-CREATE-01
- Edit -> MEM-EDIT-01
- Deactivate -> MEM-DEACTIVATE-01
- Reactivate -> MEM-REACTIVATE-01
- Delete -> MEM-DELETE-01
- Bulk Upload -> MEM-BULK-UPLOAD-01
- Export CSV -> MEM-EXPORT-01
- Retry -> reload MEM-LIST-01

#### Validations
- Search supports Name, Email, Phone, and Member ID.
- Cascading filters must respect Masters hierarchy: Country/Org -> Region -> Town -> Activity Centre.
- Export CSV must respect current filters and search.
- Delete is blocked when dependency rules are not satisfied.
- State-changing row actions are available only to Super Admin.

#### States
- Loading: Show table skeleton or spinner and disable Add Member, Bulk Upload, Export CSV, and row actions until initial load completes.
- Empty: Show "No records found."
- Error: Show "Unable to load records. Please try again." with Retry button.
- No-permission: Show "Access denied."
- Data refresh indicator: Show "Data updated. Please refresh." when another session changes the data.

#### UX Copy
- Page title: "Members"
- Add button: "Add Member"
- Bulk Upload button: "Bulk Upload"
- Export button: "Export CSV"
- Empty state: "No records found."
- Error state: "Unable to load records. Please try again."
