# Masters

---

## 1. Module Overview

- **Module Name:** Masters
- **Platform:** Admin Web
- **Layout Type:** Desktop
- **Primary Role(s):** Super Admin
- **Goal:**  
  Enable Super Admins to manage system-wide reference data for Country, Region, Town, Activity Centre, and Role Types so that access scoping, member mapping, event visibility, announcements, and reporting use a consistent source of truth.

---

## 4. Screens & Interaction Specs

### 4.1 Country Listing Screen

- **Screen ID:** MAST-COUNTRY-LIST-01
- **Screen Type:** Listing
- **Primary Action:** Add Country
- **Secondary Actions:** Edit, Activate, Deactivate, Delete, Retry

#### Entry Points
- Click Masters > Country from left navigation.
- Default landing screen after clicking Masters.
- Redirect after Country create, update, status change, or delete.

#### UI Layout
- Page Header: "Country"
- Helper Text: "Manage Organization/National records used as the top-level Masters scope."
- Sub-Section Tabs: Country, Region, Town, Activity Centre, Role Types
- Filter Bar: Search by Country Name, Status filter
- Primary CTA: Add Country
- Data Table
- Pagination

#### Components
- Search input
- Status dropdown filter
- Add Country button
- Country data table
- Row action buttons: Edit, Activate/Deactivate, Delete
- Toast notifications
- Pagination controls

#### Data Table
| Column | Type | Click Behavior | Notes |
|------|-----|----------------|------|
| Country Name | Text | None | Country represents Organization/National, HSS UK |
| Status | Badge | None | Active / Inactive |
| Last Updated | DateTime | None | Display in local timezone based on opened location |
| Actions | Buttons | Edit / Activate-Deactivate / Delete | Delete allowed only when no dependencies exist |

#### Navigation Rules
- Country tab -> MAST-COUNTRY-LIST-01
- Region tab -> MAST-REGION-LIST-01
- Town tab -> MAST-TOWN-LIST-01
- Activity Centre tab -> MAST-CENTRE-LIST-01
- Role Types tab -> MAST-ROLETYPE-LIST-01
- Add Country -> MAST-COUNTRY-CREATE-01
- Edit -> MAST-COUNTRY-EDIT-01
- Activate/Deactivate -> MAST-COUNTRY-STATUS-01
- Delete -> MAST-COUNTRY-DELETE-01
- Retry -> reload MAST-COUNTRY-LIST-01

#### Validations
- Country Name must be unique system-wide.
- Country Name is required when creating or editing.
- Delete is blocked when the Country has Regions, Members, or Events.
- Deactivate is blocked when the Country has active child records.

#### States
- Loading: Show table skeleton and disable all row actions until records load.
- Empty: Show "No records found. Click Add to create."
- Error: Show "Unable to load records. Please try again." with Retry button.
- No-permission: Show "Access denied."

#### UX Copy
- Add button: "Add Country"
- Empty state: "No records found. Click Add to create."
- Error state: "Unable to load records. Please try again."

- Blocked delete: "Cannot delete. This record is in use."

### Confirmation Messages
- Status change title: "Confirm Status Change"
- Status change message: "Are you sure you want to activate/deactivate this record?"
- Delete title: "Confirm Deletion"
- Delete message: "Are you sure you want to delete this record?"

### Inline Validation Rules
- Field-level errors must be displayed directly below the affected field.
- Form-level error summary is not required.
- Internal IDs and technical error details must not be shown in the prototype copy.
