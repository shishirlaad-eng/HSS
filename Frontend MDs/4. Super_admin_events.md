# Events

---

## 1. Module Overview

- **Module Name:** Events
- **Platform:** Admin Web
- **Layout Type:** Desktop
- **Primary Role(s):** Super Admin
- **Goal:**  
  Enable Super Admins to view, search, filter, create, and govern system-wide events across the Masters hierarchy while enforcing audit logging, safeguarding constraints, payment/refund guardrails, and edit/delete cutoff rules.

---

## 2. Navigation & Entry Points

### 2.1 Left Navigation / Global Entry
- **Menu Label:** Events
- **Menu Icon (suggested):** calendar
- **Menu Level:** Primary
- **Default Landing Screen ID:** EVT-LIST-01

### 2.2 Visibility Rules
- Visible to:
  - Yes: Super Admin
  - No: All other roles

## 4. Screens & Interaction Specs

### 4.1 Events Listing Screen

- **Screen ID:** EVT-LIST-01
- **Screen Type:** Listing
- **Primary Action:** Create Event
- **Secondary Actions:** View Details, Modify, Activate, Deactivate, Cancel, Override Approval, Delete, Retry

#### Entry Points
- Click Events from Admin Web left navigation.
- Redirect from Dashboard to Events Listing.
- Redirect after successful event creation.
- Back action from Event Details.

#### UI Layout
- Page Header: "Events"
- Helper Text: "View and govern events across all Masters scopes."
- Advanced Filter Bar
- Primary CTA: Create Event
- Data Table
- Pagination
- Toast notification region

#### Components
- Search input for Event Title, Event ID, or location hierarchy keywords
- Country dropdown filter
- Region dropdown filter, cascaded by Country
- Town dropdown filter, cascaded by Region
- Activity Centre dropdown filter, cascaded by Town
- Participant Status dropdown filter: Pending, Approved, Rejected, Checked-in, Refunded
- Payment Type dropdown filter: Paid, Free
- Date range filters: Start Date and End Date
- Create Event button
- Events data table
- Row action buttons: View Details, Modify, Activate/Deactivate, Cancel, Override Approval, Delete
- Disabled action tooltip for blocked Modify/Delete states
- Pagination controls
- Retry button for load failures

#### Data Table
| Column | Type | Click Behavior | Notes |
|------|-----|----------------|------|
| Event ID | Text | Click -> EVT-DETAIL-01 | Unique identifier |
| Event Title | Text | Click -> EVT-DETAIL-01 | Searchable event title/name |
| Country | Text | None | From Masters |
| Region | Text | None | From Masters |
| Town | Text | None | From Masters |
| Activity Centre | Text | None | From Masters |
| Start Date/Time | DateTime | None | UK display |
| End Date/Time | DateTime | None | UK display |
| Payment Type | Badge | None | Paid / Free |
| Participant Status Summary | Text/Badge | None | Counts by status where available |
| Last Updated | DateTime | None | UK display |
| Actions | Buttons | View / Modify / Activate-Deactivate / Cancel / Override / Delete | Show only actions allowed by current state |

#### Navigation Rules
- Events menu -> EVT-LIST-01
- Event ID click -> EVT-DETAIL-01
- Event Title click -> EVT-DETAIL-01
- View Details -> EVT-DETAIL-01
- Create Event -> EVT-CREATE-01
- Modify -> EVT-MODIFY-01
- Activate/Deactivate -> EVT-STATUS-01
- Cancel -> EVT-CANCEL-01
- Override Approval -> EVT-OVERRIDE-01
- Delete -> EVT-DELETE-01
- Retry -> reload EVT-LIST-01

#### Validations
- Search supports Event Title, Event ID, and location hierarchy keywords.
- Cascading filters must respect Masters hierarchy: Country -> Region -> Town -> Activity Centre.
- Participant status filter values are Pending, Approved, Rejected, Checked-in, and Refunded.
- Payment type filter values are Paid and Free.
- Date range filtering must support Start Date and End Date.
- Modify is allowed only when current datetime is before event start datetime.
- Delete is allowed only when current datetime is before event start datetime.
- Delete is blocked for completed events.
- Super Admin actions must not bypass OTP, consent, safeguarding, payment/refund, or audit rules.

#### States
- Loading: Show table skeleton or spinner and disable Create, Modify, Cancel, Override, Delete, and row actions until initial load completes.
- Empty: Show "No records found."
- Error: Show "Unable to load records. Please try again." with Retry button.
- No-permission: Show "Access denied."
- Data refresh indicator: Show "Data updated. Please refresh." when another session changes event data.

#### UX Copy
- Page title: "Events"
- Create button: "Create Event"
- Empty state: "No records found."
- Error state: "Unable to load records. Please try again."
- Modify blocked tooltip: "Event cannot be edited after it starts."
- Delete blocked tooltip: "The event cannot be deleted after it starts."

- End Date/Time picker
- Payment Type dropdown: Paid, Free
- Pricing details section shown when Payment Type is Paid

#### Form Fields
| Field | Type | Required | Default |
|------|-----|----------|--------|
| Event Title | Text | Yes | None |
| Country | Dropdown | Yes | None |
| Region | Dropdown | Yes | None |
| Town | Dropdown | Yes | None |
| Activity Centre | Dropdown | Yes | None |
| Start Date/Time | DateTime | Yes | None |
| End Date/Time | DateTime | Yes | None |
| Payment Type | Dropdown | Yes | None |
| Pricing Details | Fields | Required if Paid | None |
| Capacity | Number | TODO: Confirm | None |
| Registration Approval Required | Yes/No | TODO: Confirm | None |

#### Validations
- Event Title is required.
- Country, Region, Town, and Activity Centre are required.
- Cascading dropdown selections must follow valid Masters hierarchy.
- Inactive Masters values must not be selectable for new events unless historical selection is later confirmed.
- Start Date/Time is required.
- End Date/Time is required.
- Start Date/Time must be earlier than End Date/Time.
- Payment Type is required and must be Paid or Free.
- Pricing details are required when Payment Type is Paid.
- Save is blocked when audit logging fails.
- Save is blocked when safeguarding or payment/refund guardrails would be violated.
- Show field-level validation below each affected field.
- Disable Save while saving.

#### Navigation Rules
- Save success -> close modal -> EVT-LIST-01 refreshed
- Save validation failure -> remain on EVT-CREATE-01
- Save submission failure -> remain on EVT-CREATE-01
- Cancel -> close modal -> EVT-LIST-01

#### States
- Loading: Disable Save and show spinner while request is in-flight.
- Empty: Not applicable.
- Error: Show toast "Unable to save. Please try again."
- No-permission: Show "Access denied."
